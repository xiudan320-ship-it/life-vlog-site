# 日记画廊页面特例

日记画廊沿用 `MASTER.md` 的 Life Archive 语义色、细边界、圆角卡片和内容优先层级；桌面保留四列日记卡片与现有横向媒体轨道，移动范围使用账号偏好切换单列阅读或双列速览。页面由 `modules/diary-gallery-view.js` 和 `modules/diary-feed-controller.js` 渲染，设置由外观与使用分区中的“手机列表布局”单选组管理。

## 响应式布局

- 复用应用已有 920px 移动断点；断点以上保持桌面四列与媒体轨道，断点内默认双列，用户可选单列。
- 单列画廊使用一列卡片，卡片按正文、图片和操作自然增高；双列画廊使用两列卡片，保持现有瀑布流密度。
- 切换列数时立即重绘媒体布局，并保留当前可见日记的屏幕位置；窗口跨过 920px 时同步切换移动封面／宫格与桌面轨道。

## 媒体展示

| 每篇图片数 | 单列 | 双列 |
| --- | --- | --- |
| 0 | 不渲染空图片框 | 不渲染空图片框 |
| 1 | 保留大图预览 | 保留大图预览 |
| 2 | 两个等大方格 | 第一张封面和“2 张”标记 |
| 3 | 三个等大方格 | 第一张封面和“3 张”标记 |
| 4 | 2×2 方格 | 第一张封面和总数 |
| 5、6 | 3 列方格，末位自然留空 | 第一张封面和总数 |
| 7 及以上 | 前六张组成 3×2 宫格，第六格显示 `+N` | 第一张封面和总数 |

- 宫格间距使用 5px；各缩略格使用 `contain` 保持照片原比例，表面色填充留白。区块比例依据原图尺寸并限制在 0.72–1.55 之间；缺失尺寸使用 0.8 的安全比例。
- 双列多图卡片只创建第一张媒体预览，不挂载其余隐藏缩略图；数量标记不是嵌套按钮。单列预览的前六张保留原始相册索引，`+N` 按钮带“查看全部 X 张图片，从第 6 张开始”可访问名称。
- 视频和 Live Photo 继续展示类型标记；动态媒体源只在用户打开相册后加载。图片失败反馈留在原格中，重试不会打开查看器或改变索引。
- 桌面媒体轨道继续支持全部图片浏览和“查看全部”入口，不改变原有桌面相册交互。

## 交互与验收

- 普通格子从自身的原始索引进入完整相册；`+N` 从第六张打开，用户仍可继续查看余下图片。双列封面从第一张进入全部图片。
- 画廊模式使用已有账号作用域偏好，默认双列；秘藏布局保持独立。视图重绘不得丢失正文展开、收藏、评论、图片顺序或阅读位置。
- 设置单选组遵守设置页面的名称、焦点、方向键和 44px 触控规则；画廊在浅色／深色、reduced-motion 和大字号下保持可读与无横向溢出。
- 检查 375、390、430px 手机宽度，768px 与 844×390px 移动视口，以及 1024/1440px 桌面；桌面为四列轨道，移动按所选模式展示封面或宫格。
