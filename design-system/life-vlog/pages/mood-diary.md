# 心情日记页面特例

页面沿用 `MASTER.md` 的 Life Archive 设计语言，并在 `styles/mood-diary.css` 中局部实现：紧凑月历、细边界、珊瑚色今天标记、玻璃心情罐、成员摘要卡和宽松的历史列表。心情素材按固定枚举从 `MOOD_META` 取路径，owner 方形席位在日历单元内位于最早加入的另一位成员圆形席位之前；月历图例、最多心情和趋势图例使用真实昵称；素材加载失败只能显示文字错误态。

交互特例：

- Picker 使用受控轨道容器中的环形定位，不使用普通 2×4 网格；每个按钮至少 44px，支持键盘焦点和 reduced-motion。
- 编辑器允许空正文，正文上限 5000 Unicode 字符，标签最多 8 个且单个最多 20 个字符；保存期间禁用提交。
- 弹层提供关闭按钮、遮罩和 Escape；脏编辑离开前确认；未来日期保持可感知的阻塞提示。
- 月历和历史在 375px、横屏和 200% 放大下不得出现横向溢出；颜色、焦点和文字均需在浅色/深色主题可辨识。
- 月视图首屏只保留月份工具栏、完整 4～6 周月历和图例；可见标题块与顶部“全部日记”移除，语义标题仍保留给页面结构和焦点管理。
- 月度汇总按“玻璃心情罐 → 每位成员最多心情 → 三档趋势”排列；罐体最多 62 枚素材，视觉元数据由记录身份确定，不因普通 render 或列表返回而改变。罐口、瓶颈、圆肩、鼓腹和双线底座共享 `0 0 360 440` 坐标系；`mood-jar-physics.js` 使用同一几何的瓶口安全出生点、曲面瓶壁、椭圆瓶底和圆形粒子碰撞，固定步长求解后把结果交给唯一 rAF 写入内层 `transform`/`opacity`。素材必须位于 `.mood-jar-viewport` 的内腔裁切区内，进入视口约 35% 后才允许从 `(180,52)` 罐口播放一次下落。瓶体舞台本身是原生 `button`，点击、Enter/Space 都从当前月份完整数据重播；重播中再次激活会取消旧序列，月份切换、路由离开和 destroy 会清理循环，reduced-motion 直接显示同一求解器的最终态并播报状态。
- 趋势使用原生响应式 SVG，必须同时提供 `viewBox`、动态宽高和 `preserveAspectRatio`；手机画布约 `390×360`，记录较少时按真实有记录日期等距展开，避免月底点堆在右端。两席必须同时使用颜色、实线/虚线和方/圆点形区分，连续记录用实线，缺失日期用连接两个真实端点的低强调虚线桥，单点仍显示；SVG 只负责绘图和指针命中，HTML button overlay 是唯一键盘焦点路径，图下始终提供文本摘要和可展开的按日明细，点位命中区至少 44×44px。
- 月度汇总的保存/编辑/删除先即时反馈，再用当前月份的云端 canonical 结果覆盖；读取失败保留成功写入结果并显示可重试提示。
- 今日概览在 375/390/430 与 844×390 下固定为两列单行；席位采用 56px 素材加单行省略文案，素材不得超过 64px，整席触控区域不得小于 44px，130% 字号仍不得换行或产生页面横向滚动。
- Picker、编辑和详情是应用壳中的唯一全局 overlay；从概览关闭时必须恢复 gallery 的 URL、滚动与触发焦点，从日历关闭时必须恢复日历上下文。顶部导航不提供第二个心情入口。
