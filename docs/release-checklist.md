# 发布前验收

每次发布前都要完成两层检查：先跑本地回归，再用测试账户打开线上地址做一次真实验收。任意一层失败都不要发布。

## 1. 本地检查

```powershell
pnpm test
```

这一步检查语法、静态结构、桌面端和手机端的基础布局。

## 2. 线上测试账户检查

测试账号保存在当前 Windows 用户专属的 DPAPI 加密文件中：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\test-release.ps1
```

凭据文件位于：

`%LOCALAPPDATA%\LifeVlog\release-test-credential.xml`

文件内的密码由 Windows DPAPI 加密，只能由保存它的 Windows 用户解密。测试脚本只在子进程中短暂注入登录信息，结束时会立即清除环境变量。

自动检查会在桌面尺寸和手机尺寸下登录线上页面，确认登录状态、账号入口、日记/菜谱/心愿导航和页面宽度没有异常；还会验证已完成心愿的回执布局与详情，以及收藏日记在刷新后的持久化和取消收藏。收藏检查使用一条临时 D1 日记夹具，脚本结束时会清理日记、收藏、评论和通知。

## 3. 手动验收清单

使用测试账户分别在桌面端 `1440 x 900` 和手机端约 `390 x 844` 检查：

- 登录、退出、刷新和回到前台后会话仍然正常。
- 日记：打开/关闭、长文滚动、多图切换、图片预览、评论、回复、收藏、编辑和删除。
- 菜谱：新建、封面上传/粘贴、编辑、删除和详情图片显示。
- 心愿：新建、图片上传、编辑、完成反馈、删除和完成/未完成筛选。
- 秘藏：密码进入、文件夹/相册、上传、Tag 添加删除、收藏、移动、排序和图片预览。
- 通知：新日记、评论和回复提示；打开后提示会消失；自己发布的内容不提醒自己。
- 离线与缓存：断网时能打开已缓存内容，恢复网络后不会重复上传或重复请求。
- 深色/浅色模式、头像、昵称、家庭成员名称和长列表滚动没有错位或溢出。

发现问题时记录：设备/浏览器、页面、操作步骤、预期结果、实际结果和截图。修复后重新从第 1 步开始验收。

## 凭证规则

- 测试密码只通过本机 DPAPI 加密凭据文件提供。
- 不把密码、Worker token、邀请码、邮箱密钥提交到 Git。
- 发布前检查 `git diff`，确认没有凭证、临时截图和本地配置文件。
